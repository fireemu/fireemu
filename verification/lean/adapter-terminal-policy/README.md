# Terminal color policy in Lean 4

A normalized environment policy gives explicit opt-out priority, then explicit force, then terminal and platform capability checks. Theorems pin these precedence rules and the Windows fallback. Rust replays synthetic environment closures for both platforms and includes empty values, case-insensitive boolean spellings and redirected streams. Stream detection and the process-local cache remain operating-system observations.
