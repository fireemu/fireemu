# Ordered JSON in Lean 4

An object is an ordered list of entries. Lookup finds the first matching key. Projection to an ordinary JSON object keeps the last matching key. The proofs distinguish those ends of a duplicate list and pin the order and whitespace of pretty printing.

The executable generates an object grammar with null, booleans, unsigned integers, strings, scalar arrays and shallow objects. Its cases include duplicate and nonalphabetical keys, ordinary Unicode, quotes, backslash, tabs and newlines. Rust parses the generated bytes and checks exact pretty output, reparsing, first lookup and conversion to an ordinary JSON value. Invalid inputs, depth limits, floats and other escape spellings are outside the modeled fragment.

Regenerate the fixture with the pinned Lean toolchain.

```sh
lake build
lake exe corpus > ../../../crates/fireemu-adapter-functions/tests/fixtures/lean-functions-ordered-json.corpus
```

Run the Rust replay from the workspace root.

```sh
cargo nextest run -p fireemu-adapter-functions -E 'binary(functions_ordered_json_lean_corpus)'
```
