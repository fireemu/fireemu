---

`fireemu up`은 `http://127.0.0.1:4000/ui/`에서 Emulator UI를 제공합니다. 데이터를 탐색하고 변경하고, 함수를 실행하고, Security Rules 결정을 읽고, 시계를 이동하는 데 사용합니다.

## UI 열기

```sh
# Another port
npx fireemu up --ui-port 4001

# No UI
npx fireemu up --ui-port 0

# exec starts no UI unless asked
npx fireemu exec --ui -- npm test
```

기본 포트가 사용 중이면 `up`은 UI 없이 시작되므로 시작 출력을 확인하십시오.

## 표시되는 내용

| 페이지 | 할 수 있는 작업 |
| --- | --- |
| **Overview** | 프로젝트, 버전, 가상 시계(멈춤 또는 실제 시간을 따름), 실행 중인 서비스, 그리고 에뮬레이터가 응답하는 `Host` 이름(기본 제공 이름, `network.allowedHosts`로 추가한 항목, 단일 레이블 이름의 허용 여부)을 확인합니다. |
| **Authentication, Firestore, Storage** | 사용자, 문서, 객체를 탐색하고 관리합니다. Authentication 페이지는 브라우저에서 직접 따라가는 로그인 또는 확인 흐름을 위해, 대기 중인 이메일 작업 코드(링크 포함)와 SMS 코드도 탭이 보이는 동안 몇 초마다 새로 고쳐 나열합니다. Authentication은 사용자를 상태와 MFA로 필터링하고, 프로젝트의 Auth 에뮬레이터 설정을 JSON으로 편집하며, 가상 시계를 다음 TOTP 구간까지 앞당깁니다. Firestore는 문서를 일반 JSON으로 편집하고 복제하며, JSON, 값, 필드 경로를 복사하고, 만료된 TTL 문서를 정리하고, 활성 Listen 스트림을 만료시키며, 누락된 인덱스 보고서를 복사하거나 지웁니다. Storage는 객체의 사용자 지정 메타데이터를 편집합니다. |
| **Functions** | 등록된 함수와 각 함수의 런타임(Node.js 또는 Python, 그리고 `firebase.json`이 선언한 `runtime`), 트리거, 호출 결과와 로그, 런타임 상태를 확인합니다. 런타임 상태에는 대기 중, 실행 중, 재시도 대기 중 또는 데드 레터 처리된 작업, 이벤트 큐가 가득 차 있는 동안 보류된 Auth 이벤트, 진행 중인 작업, 각 코드베이스 러너의 상태, 러너가 찾았지만 서비스할 수 없었던 export가 포함됩니다. 예약 함수를 즉시 실행하거나 시계를 다음 발생 시점까지 앞당길 수 있습니다. 호출 패널에는 다시 불러올 수 있는 최근 호출 목록이 있고, Authentication 사용자를 고를 수 있으며(UI가 그 사용자의 ID 토큰을 발급합니다), 호출을 `curl`로 복사할 수 있고, 로그를 구조화된 보기로 표시합니다. |
| **Pub/Sub** | 토픽, 구독, 스냅샷을 나열, 생성, 삭제하고, 메시지를 게시하고, 메시지를 pull하여 확인 응답(ack)하고, 구독을 스냅샷으로 seek합니다. Pub/Sub 에뮬레이터가 실행 중일 때 표시됩니다. |
| **Remote Config** | 기본 프로젝트의 템플릿(파라미터, 조건, 버전 이력, ETag)을 읽고, 템플릿을 검증하거나 게시하고, 이전 버전으로 롤백하며, `onConfigUpdated` 핸들러에 합성 업데이트 이벤트를 보냅니다. [로컬 템플릿 관리](https://github.com/fireemu/fireemu/blob/main/docs/remote-config.md)와 같은 템플릿 저장소를 사용하므로 버전과 ETag가 Admin SDK가 보는 것과 일치합니다. 편집과 게시는 기본 프로젝트에서만 할 수 있습니다. |
| **Hosting** | Fireemu가 제공하는 사이트, 로컬 URL, 공개 디렉터리(시작 시 존재하지 않았다면 경고와 함께), 그리고 적용 순서대로 정렬된 리라이트, 리디렉션, 헤더를 확인합니다. 이 페이지는 `firebase.json`을 읽으며 요청을 기록하지 않습니다. |
| **Realtime Database** | 경로의 데이터를 탐색하고, 로컬 관리자로서 교체, 패치, 삭제하고, 데이터 트리로 보고, 인스턴스의 Rules를 읽고 교체하며, 익명 요청을 실행해 Rules가 어떻게 응답하는지 확인합니다. |
| **Alerts** | Firebase 알림을 이를 수신하는 함수에 게시합니다. |
| **Rules** | 추적된 최신 Firestore Security Rules 결정 100개를 제한된 표현식 결과와 함께 읽습니다. 거부된 결정만 표시하거나 경로, 메서드, UID로 필터링하고, 로드된 규칙의 커버리지를 볼 수 있습니다. 추적은 UI 또는 첫 제어 API 읽기와 함께 시작되며, 새 규칙 집합은 이력을 지웁니다. 진단 한계는 [Security Rules](../security-rules/)를 참조하십시오. |
| **App Check** | 등록된 앱과 디버그 토큰을 확인합니다. |
| **Runtime** | 가상 시계를 앞으로 이동하거나, **Allow moving backwards**로 뒤로 이동하고, 장애 계획(아래 참조)을 설치하며, 적용 중인 한도 카탈로그(**Load limits**)와 기능 매니페스트(**Load capabilities**)를 불러옵니다. |

## 화면 이동과 편의 기능

- **명령 팔레트**: <kbd>Ctrl</kbd>+<kbd>K</kbd>(macOS에서는 <kbd>⌘</kbd>+<kbd>K</kbd>)를 누르거나 사이드바에서 **Search or jump to**를 선택합니다. 페이지 이름을 입력하면 그 페이지를 열고, `users/alice` 같은 Firestore 경로를 입력하면 기본 데이터베이스에서 그 문서나 컬렉션을 엽니다. 세션 전환, 테마 전환, `.env` 줄 복사, 가상 시계 정지, 재개, 앞당기기(+1시간, +1일) 같은 작업도 선택할 수 있습니다.
- **헤더의 시계와 장애 계획**: 헤더에는 빠른 시계 조작(+1분, +15분, +1시간, +1일, 정지와 재개)이 있습니다. 장애 계획이 설치되어 있는 동안에는 규칙 수와 실행된 수를 보여 주는 표시기와, 확인을 요청하는 **Clear fault plan** 동작도 표시합니다.
- **테마**: 사이드바 아래쪽의 버튼은 시스템 설정, 밝은 테마, 어두운 테마를 차례로 전환합니다. 직접 선택한 테마는 이 브라우저에 기억됩니다.
- **Overview 수치**: 타일은 선택한 세션이 가진 것(Firestore 문서 데이터, Authentication 사용자, Storage 객체, 등록된 함수)을 보여 주고 각 페이지로 연결합니다. 데몬이 보고하지 않는 수치는 0이 아니라 대시로 표시합니다.
- **연결 스니펫**: Overview는 같은 연결 설정을 `.env` 줄, 셸 export, Web SDK 코드, Admin SDK 코드로 제공하며, 각 서비스 주소에는 **Copy** 버튼이 있습니다.
- **Firestore 필드**: 문서의 필드는 트리로 표시합니다. 각 행은 이름, 타입(정수와 double을 구분합니다), 값을 보여 주며, 맵과 배열은 필요할 때 펼칩니다. 탐색 중인 데이터베이스를 가리키는 참조는 그 문서로 가는 링크입니다.
- **Functions 검색**: 등록된 함수 위의 입력란은 이름, 리전, 트리거로 표를 필터링합니다.
- **키보드 단축키**: <kbd>?</kbd>를 누르면(또는 사이드바에서 **Shortcuts**를 선택하면) 목록을 표시합니다. <kbd>/</kbd>는 명령 팔레트를 열고, <kbd>g</kbd> 다음에 페이지 키를 누르면 그 페이지를 엽니다. 예를 들어 <kbd>g</kbd> <kbd>f</kbd>는 Firestore를 엽니다. 텍스트 입력란에 포커스가 있는 동안에는 단일 키가 아무 동작도 하지 않습니다.
- **상대 시간**: 타임스탬프 뒤에는 세션의 가상 시계로부터의 거리가 `(3 min ago)`나 `(in 2 h)`처럼 표시됩니다. 거리는 컴퓨터의 시계가 아니라 가상 시계를 기준으로 재므로, 시계를 앞으로 돌리면 바뀝니다.
- **Storage 업로드와 미리보기**: **Objects** 카드에 파일을 하나 이상 놓거나 파일 선택기에서 여러 개를 선택하면, 보고 있는 폴더 아래에 업로드합니다. 파일은 하나씩 보내며, 처음 실패하면 그 묶음의 나머지를 멈추고 그 파일 이름을 표시합니다. 업로드가 진행 중일 때 놓은 파일은 진행 중인 업로드가 끝나기를 기다린 뒤, 놓았을 때 열려 있던 폴더에 업로드합니다. 객체 상세에는 10 MiB 이하의 래스터 이미지(PNG, JPEG, GIF, WebP, AVIF, BMP, ICO)와 256 KiB 이하의 텍스트 계열 콘텐츠(텍스트, JSON, XML 등)의 미리보기를 표시합니다. SVG 이미지는 미리보기를 표시하지 않으므로 **Download**를 사용합니다. 텍스트는 항상 텍스트로 표시하며 HTML로 렌더링하지 않습니다.
- **함수 로그 JSON 정리**: 로그 위의 **Format JSON**을 선택하면 한 줄에 들어 있는 JSON 객체나 배열을 들여쓰기해 표시합니다. 레벨 필터와 텍스트 필터는 여전히 기록된 그대로의 줄을 기준으로 일치를 판단합니다.

## 장애 계획 설치

Runtime 페이지의 **Fault plan** 아래에서 다음을 수행합니다.

1. Functions 이벤트 재시도, 중복 전달, 시도 지연 또는 타임아웃, 처음 몇 번의 시도 실패 중 하나에 해당하는 레시피를 선택하고 매개변수를 입력합니다.
2. **Fill plan**을 선택합니다. 계획이 JSON 편집기에 채워지며, 설치되지는 않습니다.
3. JSON을 검토하거나 편집한 다음 **Install**을 선택해 선택한 세션에 적용합니다.

파싱 가능한 계획에는 테스트에서 같은 계획을 설치할 수 있는, 복사 가능한 `fireemu/testing` 및 제어 API 스니펫도 제공됩니다. **Clear**는 설치된 계획을 제거합니다.

## 데이터베이스 선택과 쿼리 재현

### Firestore 데이터베이스 선택

Firestore 데이터베이스 필드에는 현재 프로젝트의 알려진 데이터베이스와 최근에 연 이름이 표시됩니다. 이름을 직접 입력한 뒤 **Open database**를 선택할 수도 있습니다.

- 선택이 바뀔 때마다 카탈로그를 다시 확인하며, **Refresh**는 선택을 바꾸지 않고 카탈로그를 확인합니다.
- 카탈로그 요청의 실패는, 성공한 카탈로그 응답에 데이터베이스가 없는 경우와 별도로 보고됩니다.
- 최근 이름은 선택한 세션과 프로젝트로 범위가 한정되며 브라우저 탭의 세션 스토리지에만 보관됩니다.

### Node.js SDK로 쿼리 재현

쿼리 패널의 **Node.js SDK reproduction** 섹션은 저수준 Firestore Node.js SDK를 사용하는 스크립트를 생성합니다. 이를 통해 64비트 정수와 타임스탬프 나노초를 포함한 형식 있는 쿼리 값이 보존됩니다.

스크립트에 나열된 패키지를 설치하고 `query.cjs`로 저장한 다음, 실행하기 전에 `FIRESTORE_EMULATOR_HOST`를 로컬 Firestore 포트로 설정하십시오. 스크립트는 루프백이 아닌 엔드포인트를 거부합니다. 콘솔 쿼리와 마찬가지로 클라이언트 Security Rules를 테스트하지 않고 로컬 관리자 접근을 사용합니다.

쿼리 초안은 데이터베이스별로 유지됩니다. Firestore 뷰는 변경된 경로를 기준으로 영향받은 문서를 새로 고치며, 행에 사용할 수 있는 업데이트 시각이 없으면 멤버십 새로 고침을 수행합니다.

## 연결 확인과 공유 가능한 Functions 필터

### 연결 배지

헤더의 연결 배지는 모든 제품 리스너의 상태가 아니라 제어 API의 응답을 나타냅니다.

- 마지막으로 성공한 확인은 에뮬레이터의 가상 시계와 무관하게 실제 시각(wall-clock)을 사용합니다.
- 확인이 실패하면 이전에 성공한 타임스탬프가 유지되며, 선택한 세션을 바꾸면 해당 대상이 응답할 때까지 지워집니다.
- 연결 변경은 보조 기술에 알려집니다.

### Functions 필터 링크

Functions의 함수 이름 및 로그 수준 필터는 URL에 유지됩니다. 검색 텍스트는 선택한 세션과 프로젝트로 범위가 한정되어 탭의 세션 스토리지에 남으며, **Include search text in the shared link**를 명시적으로 선택하고 **Copy filter link**를 사용하는 경우에만 링크에 포함됩니다. 공유하기 전에 검색 텍스트를 검토하십시오.

- 링크에는 필터 설정이 들어 있을 뿐 로그 레코드의 저장된 사본이 들어 있지 않습니다. 다른 사용자가 링크를 열 때는 레코드가 더 이상 보존되지 않을 수 있습니다.
- 브라우저 스토리지를 사용할 수 없으면 비공개 텍스트는 페이지가 마운트된 동안에만 유지됩니다.
- 이벤트 링크는 해당 세션을 선택하며, 브라우저의 뒤로 가기나 앞으로 가기로 다시 방문한 경우도 마찬가지입니다. 이벤트가 더 이상 보존되지 않으면 페이지가 만료되었다고 알려 줍니다.

### 클립보드

클립보드 접근이 실패하면, Overview 페이지는 성공했다고 보고하는 대신 키보드로 직접 복사할 수 있는 포커스된 읽기 전용 텍스트 필드를 제공합니다.
