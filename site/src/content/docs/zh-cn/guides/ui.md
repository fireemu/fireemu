`fireemu up` 在 `http://127.0.0.1:4000/ui/` 提供 Emulator UI。使用它可以浏览和更改数据、运行函数、查看安全规则决策以及推进时钟。

## 打开 UI

```sh
# Another port
npx fireemu up --ui-port 4001

# No UI
npx fireemu up --ui-port 0

# exec starts no UI unless asked
npx fireemu exec --ui -- npm test
```

如果默认端口被占用，`up` 会在没有 UI 的情况下启动；请查看启动输出。

## 显示内容

| 页面 | 可以做什么 |
| --- | --- |
| **Overview** | 查看项目、版本、虚拟时钟（冻结或跟随真实时间）和正在运行的服务，以及模拟器应答的 `Host` 名称：内置名称、您通过 `network.allowedHosts` 添加的条目，以及是否允许单标签名称。 |
| **Authentication、Firestore 和 Storage** | 浏览和管理用户、文档和对象。 Authentication 页面还会列出待处理的邮件操作码（含其链接）和短信验证码，在标签页可见期间每隔几秒刷新一次，用于你在浏览器中手动走一遍的登录或验证流程。 |
| **Functions** | 查看已注册的函数及各自的运行时（Node.js 或 Python，以及您的 `firebase.json` 声明的 `runtime`）、触发器、调用结果和日志，以及运行时状态：待处理、运行中、等待重试或进入死信的工作，事件队列已满时暂存的 Auth 事件，进行中的任务，每个代码库运行器的状态，以及运行器找到但无法提供的导出。立即运行定时函数，或将时钟推进到其下一次触发。 |
| **Hosting** | 查看 Fireemu 提供的站点、其本地 URL、公共目录（启动时不存在则显示警告），以及按应用顺序排列的重写、重定向和标头。该页面读取您的 `firebase.json`；不记录请求。 |
| **Realtime Database** | 浏览某个路径上的数据，以本地管理员身份替换、修补或删除它，读取和替换实例的规则，并运行匿名请求以查看规则如何应答。 |
| **Alerts** | 向监听 Firebase 提醒的函数发布提醒。 |
| **Rules** | 查看最新的 100 条已跟踪的 Firestore 安全规则决策，附带有界的表达式结果。跟踪在打开 UI 或首次读取控制 API 时开始；新的规则集会清除历史记录。诊断限制参见 [安全规则](../security-rules/)。 |
| **App Check** | 查看已注册的应用和调试令牌。 |
| **Runtime** | 向前推进虚拟时钟，或通过 **Allow moving backwards** 向后调整，并安装故障计划（见下文）。 |

## 导航与便捷功能

- **命令面板**：按 <kbd>Ctrl</kbd>+<kbd>K</kbd>（macOS 上为 <kbd>⌘</kbd>+<kbd>K</kbd>），或选择侧边栏中的 **Search or jump to**。输入页面名称可打开该页面；输入 `users/alice` 这样的 Firestore 路径可在默认数据库中打开对应的文档或集合；也可以选择操作：切换会话、切换主题或复制 `.env` 行。
- **主题**：侧边栏底部的按钮在系统设置、浅色和深色之间循环切换。明确选择的主题会保存在此浏览器中。
- **Overview 数据**：各卡片显示所选会话当前保存的内容（Firestore 文档数据、Authentication 用户、Storage 对象、已注册的函数），并链接到相应页面。守护进程未报告的数据显示为短横线，而不是 0。
- **连接代码片段**：Overview 以 `.env` 行、shell export、Web SDK 代码和 Admin SDK 代码的形式提供相同的连接设置，每个服务地址都有 **Copy** 按钮。
- **Firestore 字段**：文档的字段以树形显示。每行显示名称、类型（区分整数和浮点数）和值；映射和数组可按需展开。指向当前浏览的数据库内的引用是指向该文档的链接。
- **Functions 搜索**：已注册函数上方的输入框可按名称、区域或触发器筛选表格。
- **键盘快捷键**：按 <kbd>?</kbd>（或选择侧边栏中的 **Shortcuts**）可查看列表。<kbd>/</kbd> 打开命令面板；先按 <kbd>g</kbd> 再按页面对应的键可打开该页面，例如 <kbd>g</kbd> <kbd>f</kbd> 打开 Firestore。焦点位于文本输入框时，单键快捷键不起作用。
- **相对时间**：时间戳后面会显示它与会话虚拟时钟之间的间隔，例如 `(3 min ago)` 或 `(in 2 h)`。该间隔以虚拟时钟为基准，而不是您计算机的时钟，因此推进时钟后显示也会变化。
- **Storage 上传和预览**：将一个或多个文件拖放到 **Objects** 卡片上，或在文件选择器中选择多个文件，即可上传到当前查看的文件夹。文件逐个发送；第一次失败会中止本批其余文件并显示该文件名。上传进行中拖放的文件会等待当前上传完成，然后上传到拖放时打开的文件夹。对象详情会为不超过 10 MiB 的光栅图片（PNG、JPEG、GIF、WebP、AVIF、BMP、ICO）和不超过 256 KiB 的文本类内容（文本、JSON、XML 等）显示内嵌预览。SVG 图片不提供预览，请使用 **Download**。文本始终按文本显示，不会作为 HTML 渲染。
- **JSON 格式的函数日志**：选择日志上方的 **Format JSON**，可将日志行中的 JSON 对象或数组缩进显示。级别和文本筛选器仍按日志行的原始内容进行匹配。

## 安装故障计划

在 Runtime 页面的 **Fault plan** 下：

1. 选择一个配方，用于重试 Functions 事件、重复投递、延迟某次尝试或使其超时，或让前几次尝试失败，然后输入其参数。
2. 选择 **Fill plan**。它会将计划放入 JSON 编辑器中，但不会安装。
3. 检查或编辑 JSON，然后选择 **Install** 将其应用到所选会话。

可解析的计划还会提供可复制的 `fireemu/testing` 和控制 API 代码片段，用于从测试中安装同一计划。**Clear** 会移除已安装的计划。

## 数据库选择和查询重现

### 选择 Firestore 数据库

Firestore 数据库字段提供当前项目的已知数据库和最近打开过的名称。您也可以直接输入名称并选择 **Open database**。

- 选择改变时会再次检查目录；**Refresh** 会在不改变选择的情况下检查目录。
- 目录请求失败与成功的目录响应中不存在某个数据库，会分别报告。
- 最近使用的名称按所选会话和项目区分，并且仅保留在浏览器标签页的会话存储中。

### 使用 Node.js SDK 重现查询

查询面板的 **Node.js SDK reproduction** 部分会生成一个使用底层 Firestore Node.js SDK 的脚本。这样可以保留带类型的查询值，包括 64 位整数和时间戳的纳秒部分。

安装脚本中列出的包，将其保存为 `query.cjs`，并在运行前将 `FIRESTORE_EMULATOR_HOST` 设为您的本地 Firestore 端口。该脚本会拒绝非环回地址的端点。与控制台查询一样，它使用本地管理员访问权限，而不是测试客户端安全规则。

查询草稿按数据库保留。Firestore 视图会根据更改的路径刷新受影响的文档；当某行缺少可用的更新时间时，会进行成员资格刷新。

## 连接检查和可分享的 Functions 筛选器

### 连接徽章

标题栏的连接徽章描述的是来自控制 API 的响应，而不是每个产品监听器的健康状况。

- 其上次成功检查使用的是挂钟时间，与模拟器的虚拟时钟无关。
- 检查失败时会保留上一次成功的时间戳；更改所选会话会清除它，直到该目标作出应答。
- 连接变化会通知辅助技术。

### Functions 筛选器链接

Functions 的函数名称和日志级别筛选器保存在 URL 中。搜索文本保留在标签页的会话存储中，并按所选会话和项目区分，除非您明确选择 **Include search text in the shared link** 并使用 **Copy filter link**。分享前请检查搜索文本。

- 链接包含筛选器设置，而不是日志记录的保存副本；当其他读者打开链接时，记录可能已不再保留。
- 当浏览器存储不可用时，私密文本仅在页面保持挂载期间保留。
- 事件链接会选中其会话，包括通过浏览器的后退或前进再次访问时。如果该事件已不再保留，页面会报告它已过期。

### 剪贴板

当剪贴板访问失败时，Overview 页面会提供一个获得焦点的只读文本字段，供您用键盘手动复制，而不是报告成功。
