## 产品

`firebase-tools` 15.28.2（Fireemu 所对照的官方模拟器版本）的 Local Emulator Suite 中的所有产品，以及 Fireemu 额外提供的功能面。

### 兼容性声明

在 `emulator` 兼容性 profile 下，并以 [`spec/compatibility/contract.json`](https://github.com/fireemu/fireemu/blob/main/spec/compatibility/contract.json) 中记录的证据为依据，Fireemu 与 firebase-tools 15.28.2 附带且 Fireemu 以对等方式提供的 Local Emulator Suite 产品兼容（Cloud Firestore、Firebase Authentication、Cloud Storage for Firebase、Cloud Functions、Cloud Pub/Sub 和 Eventarc，以及 Firestore 和 Storage 功能面上的安全规则）。它不声称覆盖完整套件，也不声称是无条件的超集，原因如下：

- Realtime Database 和 Firebase Hosting 已提供，但没有针对官方模拟器的对等声明（一个尚未弥补的差距；两者均已针对记录的用例对照生产环境验证）；
- App Hosting 和 Data Connect 已推迟；
- 不计划支持 Firebase Extensions。

## Fireemu、官方模拟器与生产环境

最常改变测试结果的差异。Fireemu 一列为默认的 `strict` profile。

| 行为 | 生产环境 | 官方模拟器 | Fireemu |
|---|---|---|---|
| 缺少复合索引的查询 | 拒绝 | 执行 | 拒绝；使用 `firestore.missingIndexes: "report"` 时执行并报告缺失的索引 |
| 向没有安全规则的项目发出的 Firestore 客户端请求 | 拒绝 | 允许 | 拒绝 |
| TOTP 多重身份验证 | 支持 | 不可用 | 支持，通过项目的 MFA 配置 |
| 指定不存在的租户的请求 | 拒绝 | 创建该租户 | 拒绝 |
| `beforeEmailSent` 阻塞函数 | 运行 | 不运行 | 运行 |
| App Check | 支持 | 不可用 | 调试令牌；无证明提供方和重放保护 |
| 定时函数 | 按 Cloud Scheduler 的计划运行 | 不按计划运行 | 按您控制的虚拟时钟运行 |
| 安全规则中未签名的模拟 ID 令牌 | 拒绝 | 接受 | 默认接受；使用 `productionExact` 时拒绝 |
| 声明的 Storage 上传校验和 | 验证 | 不验证 | 验证 |

## 生产环境验证

Fireemu 将自己的应答与从真实 Firebase 项目获取的记录进行比较。

- **已对照生产环境验证。** 该领域冻结清单中的每个条件都与记录一致，或仅以经过审查并记录在案的方式不同（已知差异）。
- **进行中。** 该领域仍在开发中。其计数描述的是已记录的条件，而不是整个领域的验证。
