`fireemu up`は、Emulator UIを`http://127.0.0.1:4000/ui/`で提供します。データの閲覧と変更、関数の実行、Security Rulesの判定の確認、クロックの操作に使えます。

## UIを開く

```sh
# Another port
npx fireemu up --ui-port 4001

# No UI
npx fireemu up --ui-port 0

# exec starts no UI unless asked
npx fireemu exec --ui -- npm test
```

デフォルトのポートが使用中の場合、`up`はUIなしで起動します。起動時の出力を確認してください。

## 表示される内容

| ページ | できること |
| --- | --- |
| **Overview** | プロジェクト、バージョン、仮想クロック(固定、または実時間に追従)、実行中のサービスと、エミュレーターが応答する`Host`名(組み込みの名前、`network.allowedHosts`で追加したエントリ、単一ラベルの名前が許可されているかどうか)を確認できます。 |
| **Authentication、Firestore、Storage** | ユーザー、ドキュメント、オブジェクトを閲覧して管理できます。Authenticationページには、ブラウザーで手作業でたどるサインインや確認のフロー向けに、保留中のメールアクションコード（リンク付き）とSMSコードも一覧表示され、タブが表示されている間は数秒ごとに更新されます。 |
| **Functions** | 登録された関数と、それぞれのランタイム(Node.jsまたはPython、および`firebase.json`が宣言する`runtime`)、トリガー、呼び出し結果とログを確認できます。また、ランタイムの状態も確認できます。保留中、実行中、リトライ待ち、またはデッドレター化された処理、イベントキューが満杯の間保留されるAuthイベント、実行中のタスク、各コードベースのランナーの状態、ランナーが見つけたが提供できなかったエクスポートです。スケジュール関数をすぐに実行するか、クロックを次の実行時刻まで進められます。 |
| **Hosting** | Fireemuが配信するサイト、そのローカルURL、publicディレクトリ(起動時に存在しなかった場合は警告付き)、適用順に並べたリライト、リダイレクト、ヘッダーを確認できます。このページは`firebase.json`を読み取ります。リクエストは記録しません。 |
| **Realtime Database** | パスのデータを閲覧し、ローカル管理者として置換、パッチ、削除できます。インスタンスのRulesの読み取りと置換、および匿名リクエストを実行してRulesがどう応答するかの確認もできます。 |
| **Alerts** | Firebaseアラートを、それを待ち受ける関数に発行できます。 |
| **Rules** | トレースされた直近100件のFirestore Security Rulesの判定を、上限付きの式の結果とともに確認できます。トレースはUIまたは最初のcontrol APIの読み取りで開始され、新しいルールセットで履歴は消去されます。診断の上限については[Security Rules](../security-rules/)を参照してください。 |
| **App Check** | 登録されたアプリとデバッグトークンを確認できます。 |
| **Runtime** | 仮想クロックを進めます(**Allow moving backwards** を使うと戻すこともできます)。また、フォールトプランをインストールします(下記を参照)。 |

## 画面の移動と便利な機能

- **コマンドパレット**: <kbd>Ctrl</kbd>+<kbd>K</kbd>（macOSでは<kbd>⌘</kbd>+<kbd>K</kbd>）を押すか、サイドバーの**Search or jump to**を選択します。ページ名を入力するとそのページを開き、`users/alice`のようなFirestoreのパスを入力すると既定のデータベースでそのドキュメントやコレクションを開きます。セッションの切り替え、テーマの切り替え、`.env`の行のコピーも選べます。
- **テーマ**: サイドバー下部のボタンで、システム設定、ライト、ダークを順に切り替えます。明示的に選んだテーマは、このブラウザに記憶されます。
- **Overviewの数値**: タイルは、選択中のセッションが保持しているもの（Firestoreのドキュメントデータ、Authenticationのユーザー、Storageのオブジェクト、登録済みの関数）を示し、各ページへリンクします。デーモンが報告しない数値は、0ではなくダッシュで表示します。
- **接続スニペット**: Overviewは同じ接続設定を、`.env`の行、シェルのexport、Web SDKのコード、Admin SDKのコードとして表示します。各サービスのアドレスには**Copy**ボタンがあります。
- **Firestoreのフィールド**: ドキュメントのフィールドはツリーで表示します。各行は名前、型（整数と浮動小数点数を区別します）、値を示し、マップと配列は必要なときに開けます。閲覧中のデータベース内を指す参照は、そのドキュメントへのリンクになります。
- **Functionsの検索**: 登録済み関数の上にある入力欄で、名前、リージョン、トリガーによって表を絞り込めます。

## フォールトプランをインストールする

Runtimeページの **Fault plan** で次の手順を行います。

1. Functionsイベントのリトライ、重複配信、試行の遅延またはタイムアウト、最初の試行の失敗に対応するレシピを選び、そのパラメーターを入力します。
2. **Fill plan** を選びます。プランがJSONエディターに入力されます。インストールはされません。
3. JSONを確認または編集し、**Install** を選んで、選択したセッションに適用します。

解析できるプランでは、テストから同じプランをインストールするための、コピー可能な`fireemu/testing`とcontrol APIのスニペットも表示されます。**Clear** はインストール済みのプランを削除します。

## データベースの選択とクエリの再現

### Firestoreデータベースを選択する

Firestoreのデータベースフィールドには、現在のプロジェクトの既知のデータベースと、最近開いた名前が候補として表示されます。名前を直接入力して **Open database** を選ぶこともできます。

- カタログは、選択が変わると再度確認されます。**Refresh** は、選択を変えずにカタログを確認します。
- カタログのリクエストの失敗は、成功したカタログのレスポンスにデータベースが存在しない場合とは別に報告されます。
- 最近の名前は、選択したセッションとプロジェクトにスコープされ、ブラウザータブのセッションストレージにのみ保持されます。

### Node.js SDKでクエリを再現する

クエリパネルの **Node.js SDK reproduction** セクションは、低レベルのFirestore Node.js SDKを使ったスクリプトを生成します。これにより、64ビット整数やタイムスタンプのナノ秒を含む、型付きのクエリ値が保持されます。

スクリプトに記載されたパッケージをインストールし、`query.cjs`として保存して、実行前に`FIRESTORE_EMULATOR_HOST`をローカルのFirestoreポートに設定してください。スクリプトは、ループバック以外のエンドポイントを拒否します。コンソールのクエリと同様に、クライアントのSecurity Rulesをテストするのではなく、ローカル管理者のアクセスを使います。

クエリの下書きはデータベースごとに保持されます。Firestoreのビューは、変更されたパスによって、影響を受けたドキュメントを更新します。行に使える更新時刻がない場合は、メンバーシップを更新します。

## 接続チェックと共有できるFunctionsフィルター

### 接続バッジ

ヘッダーの接続バッジは、control APIからのレスポンスを表すもので、すべてのプロダクトのリスナーの正常性を表すものではありません。

- 最後に成功したチェックは、エミュレーターの仮想クロックとは独立して、実時間を使います。
- チェックが失敗しても、前回成功したタイムスタンプは保持されます。選択したセッションを変更すると、その対象が応答するまでタイムスタンプは消去されます。
- 接続の変化は、支援技術に通知されます。

### Functionsのフィルターリンク

Functionsの関数名とログレベルのフィルターはURLに保持されます。検索テキストは、**Include search text in the shared link** を明示的に選択して **Copy filter link** を使わない限り、選択したセッションとプロジェクトにスコープされたタブのセッションストレージに保持されます。共有する前に検索テキストを確認してください。

- リンクに含まれるのはフィルター設定であり、ログレコードの保存済みコピーではありません。別の閲覧者がリンクを開くときには、レコードがすでに保持されていないことがあります。
- ブラウザーのストレージが使えない場合、非公開のテキストはページがマウントされている間だけ保持されます。
- イベントリンクは、ブラウザーの戻る/進むで再訪した場合も含め、そのセッションを選択します。イベントがすでに保持されていない場合、ページは期限切れと報告します。

### クリップボード

クリップボードへのアクセスに失敗した場合、Overviewページは、成功を報告する代わりに、手動でキーボードコピーするための、フォーカスされた読み取り専用のテキストフィールドを表示します。
