### 互換性の範囲

`emulator`プロファイルおよび[`spec/compatibility/contract.json`](https://github.com/fireemu/fireemu/blob/main/spec/compatibility/contract.json)の記録に基づき、Fireemuは`firebase-tools` 15.28.2のLocal Emulator Suiteのうち同等性を検証しているプロダクト（Cloud Firestore、Firebase Authentication、Cloud Storage for Firebase、Cloud Functions、Cloud Pub/Sub、Eventarc、およびFirestore/StorageのSecurity Rules）との互換性を示しています。以下の理由から、スイート全体との完全互換や無条件の上位互換は主張していません。

- Realtime DatabaseとFirebase Hostingは公式エミュレータとの互換性を主張していません（いずれも記録済みケースは本番と照合済みです）。
- App HostingとData Connectは対応を延期しています。
- Firebase Extensionsは対応予定がありません。

## Fireemu、公式エミュレータ、本番

テスト結果に影響しやすい代表的な挙動差です。Fireemu列は既定の`strict`プロファイルでの動作です。

| 動作 | 本番 | 公式エミュレータ | Fireemu |
|---|---|---|---|
| 複合インデックス未定義のクエリ | 拒否される | 実行される | 拒否される（`firestore.missingIndexes = "report"`で実行しつつ不足を報告） |
| Security Rules未設定のプロジェクトへのクライアントFirestoreリクエスト | 拒否される | 許可される | 拒否される |
| TOTP多要素認証 | 対応 | 非対応 | プロジェクトのMFA設定を通じて対応 |
| 存在しないテナントを指定したリクエスト | 拒否される | テナントを自動作成 | 拒否される |
| `beforeEmailSent`ブロッキング関数 | 実行される | 実行されない | 実行される |
| App Check | 対応 | 非対応 | デバッグトークンに対応（実機アテステーション・リプレイ保護はなし） |
| スケジュール関数 | Cloud Schedulerのスケジュールで起動される | スケジュール実行なし | 制御可能な仮想時計で実行 |
| Security Rulesでの署名なしモックIDトークン | 拒否される | 受け付けられる | 既定では受け付け、`productionExact`で拒否 |
| Storageアップロード時の申告チェックサム | 検証される | 検証されない | 検証される |

## 本番との照合

Fireemuは実際のFirebaseプロジェクトから取得した記録と自身の応答を照合しています。

- **本番検証済み**：その領域の固定インベントリに含まれる全条件が記録と一致するか、レビュー済みで文書化された既知の差異のみに収まっている状態です。
- **作業中**：現在進行中の領域です。件数は記録済みの条件数を示し、領域全体の完了を意味するものではありません。
